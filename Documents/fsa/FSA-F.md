**Date:** 2026-08-02  
**Depends on:** [`FSA.md`](./FSA.md)

## Overview

FSA-F — поверхность поиска по постам ленты. Домен смешанной интенции: пользователь ищет и «тот самый пост» (навигация), и «посты про X» (исследование). Профиль балансирует текстовую релевантность с заметным влиянием свежести и engagement-приора; это самая персонализируемая поверхность (`λ = 1.0`) — аффинити к авторам, тегам и сообществам из FIRA даёт наибольший выигрыш именно здесь.

---

## Architecture Position

**Владелец данных:** Social Content (`flora-content`). Модуль поставляет посты в свой экземпляр `FeedSearch`, инвалидацию — через `upsert`/`remove` по событиям публикации/редактирования/удаления.

**Видимость — до индексации.** FSA не проверяет права: посты приватных сообществ без членства и посты заблокированных авторов обязаны отфильтровываться владельцем данных до `upsert` либо структурными фильтрами на его стороне (нормативные инварианты FIRA.md §12 действуют и для поиска).

## Профиль (нормативный)

| Поле | Вес | positions | exact_boost |
|------|-----|-----------|-------------|
| `text` | 1.0 | ✓ | — |
| `tags` | 1.6 | — | — |
| `author_name` | 0.7 | — | — |
| `community_name` | 0.5 | — | — |

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| recency | Boost, half-life **48 ч**, вес 0.35 | лента живёт днями; старый пост находится, но уступает при равном тексте |
| static_rank | 0.4 × engagement_rank | глобальный (неперсональный) приор качества поста |
| proximity | 0.25 | «красная машина» рядом в тексте ценнее разбросанных термов |
| λ (персонализация) | **1.0** | максимально персонализируемый домен |
| expansion | prefix ≥ 3 (последний токен), fuzzy ≥ 4 | стандартный полнотекст |

Теги весят больше текста: тег — осознанная классификация автора, короткий сигнал темы.

## Документ

`FeedPost`: `id`, `text`, `tags[]`, `author_id` + `author_name`, `community_id?` + `community_name?`, `lang?`, `is_repost`, `created_at`, `engagement_rank ∈ [0,1]`.

Атрибуты (фильтры): `author_id`, `community_id`, `lang`, `kind ∈ {post, repost}`.  
Ключи аффинити: `author:{author_id}`, `tag:{tag}` на каждый тег, `community:{community_id}`.

---

## API

`FeedQuery`: `query`, `limit/offset`, `now`, `personalization (α)`, скоупы `author_id?` / `community_id?` / `lang?`, `include_reposts` (по умолчанию `true`; `false` → `none_of kind=repost`).

Персонализация действует только вместе с `PersonalizationContext`, который composition-слой строит из `AffinitySnapshot` (FIRA UIP → topic/tag, author affinity → author, членства → community). Инварианты FSA.md §5.3: `α = 0` — выдача идентична для всех пользователей.
