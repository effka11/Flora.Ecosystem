# Codecs — собственные медиакодеки Flora (R&D-трек)

Каталог для разработки собственных кодеков экосистемы: видео (**FVC**), аудио, фото.
Это **независимый от `Backend/` трек**: здесь нет C#-эталона, паритетных фикстур и freeze-окон
миграции — правила `next-architecture.md` §4/§5.3 на этот каталог не распространяются.
Интеграция кодеков в продукт (Flora.Content, Flora.Messaging, клиенты) — отдельные задачи
после соответствующих фаз миграции: форматы медиа в `bytea` до конца миграции заморожены.

## Структура и правила для параллельной работы агентов

- Каждый кодек — **свой самостоятельный cargo-workspace** в своём каталоге:
  - `flora-video/` — видеокодек FVC (битстрим `FVC1`), спека: `docs/codecs/FVC.md`.
  - `flora-audio/` — аудиокодек (владелец — агент аудио).
  - `flora-image/` — фотокодек (владелец — агент фото).
- Агент правит **только свой каталог**. Общих файлов между кодеками нет — конфликты исключены.
- Общие примитивы (range-coder, bit I/O, метрики) **не выносим** в общий crate, пока все три
  кодека не стабилизируются (правило трёх): до этого допустимо дублирование.
- Контейнер для мультиплексирования (видео+аудио) — совместное решение позже; для разработки
  каждый кодек использует свой элементарный формат (видео — IVF с FourCC `FVC1`).

## Технические соглашения (для всех трёх)

- Rust edition 2024, канал **1.97.0** (как в `Backend/`), `unsafe_code = "forbid"` (пока не
  доказана необходимость SIMD-intrinsics — сначала safe-SIMD).
- Ядро кодека — crate **без внешних зависимостей** (сборка в wasm32 обязана проходить:
  декодер поедет в браузер). CLI и инструменты — отдельные crates, зависимости разрешены.
- Лицензия: `AGPL-3.0-only` (политика репозитория, см. `LEGAL.md`).
- Декодер обязан быть **panic-free на произвольном входе** и **бит-точно детерминированным**
  (никакой платформозависимой float-математики в нормативных путях декодера).
- Проверки перед завершением задачи: `cargo fmt --all --check`, `cargo clippy --workspace
  --all-targets -- -D warnings`, `cargo test --workspace`, `cargo check --target
  wasm32-unknown-unknown` (для ядра).

> Windows без MSVC Build Tools: как и для `Backend/`, используйте локальный override
> `rustup override set 1.97.0-x86_64-pc-windows-gnu --path Codecs/<кодек>`.
