# Replicate: выбор модели под задачу

Один источник выбора модели для ассетов. Цель — не перебирать каталог каждый раз и не платить за дорогую модель там, где хватает дешёвой.

## Матрица

| # | Задача | Основная модель | Дешёвый черновик / альтернатива | Как вызывать |
|---|---|---|---|---|
| 1 | Обычная графика для презентаций: фоны, простые иллюстрации, схемы | `flux-pro` (`black-forest-labs/flux-1.1-pro`), $0.04 | `flux-schnell` ($0.003) | `replicate_generate_image`, 16:9 |
| 2 | Сложная графика: фото + графика, композиты, несколько объектов, референсы | `flux-2-max` (`black-forest-labs/flux-2-max`), до 8 референсов | `seedream` (`bytedance/seedream-5-lite`): до 14 референсов, 3K; `flux-pro` для массовых вариантов | `replicate_generate_image` |
| 3 | Иконки | `recraft-v4.1` (`recraft-ai/recraft-v4.1`) — арт-дирекшн и текст; чистый SVG — `recraft-v3` | `flux-schnell` для поиска формы | `replicate_generate_image`, 1:1, затем `replicate_remove_background` |
| 4 | Видео-презентации на основе обычной графики | `wan-2.2` (`wan-video/wan-2.2-t2v-fast`), $0.25 за 5 с | `bytedance/seedance-2.0-fast` — быстрее, со звуком | `replicate_generate_video`, 5 с на сцену |
| 5 | Сложные видео-презентации | `seedance` (`bytedance/seedance-2.0`): мультимодальный вход + нативный звук | `kling-pro` ($0.45 за 5 с) — движение; `grok-video` — клипы до 15 с | `replicate_generate_video` |
| 6 | Саунд-эффекты | `stackadoc/stable-audio-open-1.0` — текст → SFX | `declare-lab/tango`; звук под готовый клип — `mirelo/video-to-sfx-v1.5`, `tencent/hunyuanvideo-foley` | `replicate_run_model` |
| 7 | Звуковое сопровождение: музыка, фон, озвучка | Музыка — `lyria-3-pro` (`google/lyria-3-pro`, до 3 мин, вокал); озвучка — `gemini-tts` (`google/gemini-3.1-flash-tts`, 70+ языков, эмоции) | `minimax-music` (до 6 мин, с текстом песни), `musicgen` (инструментал до 30 с); дешёвая озвучка — `kokoro` | `replicate_generate_audio` / `replicate_generate_speech` |

Модели вне курируемого каталога (строки 4 частично, 6 полностью): сначала `replicate_get_model_schema` по `owner/name`, затем `replicate_run_model`. Схемы полей у них разные — не угадывать.

## Правила запуска

- **Видео по умолчанию без звука.** Любой запрос на видео рендерится молча. Звук появляется только по отдельному явному запросу («со звуком», «озвучь», «добавь музыку») — и тогда генерируется отдельной фазой (строки 6–7) и подмешивается в монтаже.
- **Как получается немое видео.** `wan-2.2` аудио-параметров не имеет — молчит по построению, безопасный дефолт. У `seedance` и `seedance-2.0-fast` параметр `generate_audio` по умолчанию `true` — выключать всегда, если звук не заказан. У `grok-imagine-video` тумблера нет — для немого видео его не выбирать.
- **Удаление дорожки — только по запросу.** Автоматически звук не вырезать. `ffmpeg -i in.mp4 -c:v copy -an out.mp4` применяется, когда пользователь явно просит убрать звук у готового клипа.
- **Проверка немоты.** После рендера: `ffprobe -v error -select_streams a -show_entries stream=index -of csv=p=0 out.mp4` — пустой вывод значит дорожки нет. Если дорожка нашлась, сообщить пользователю; молча не удалять.
- **Цена до генерации.** Всегда `replicate_estimate_cost`. Если ответ `unknown` — назвать это пользователю и дать ссылку на страницу модели; цифры не выдумывать.
- **Черновик → финал.** Композицию и промпт перебирать на дешёвой модели, финал гнать на дорогой.
- **Текст в кадре** — только `recraft-v4.1` / `recraft-v3` / `ideogram-v2`. У FLUX-моделей типографика разваливается.
- **Прозрачность** получать через `replicate_remove_background`, а не просьбой «на прозрачном фоне» в промпте.
- **Видео собирается из кадров:** ключевые кадры (строка 2) → оживление → звук отдельной фазой только по запросу. Один источник стиля на все сцены, иначе презентация выглядит сборной.
- **Потолок трат:** launcher ставит `REPLICATE_MAX_COST_USD=0.50` на одно предсказание. Поднимать точечно через переменную окружения.
- **Выход:** `local/replicate-output` (gitignored). Перенос ассета в репозиторий — осознанный `move`, не автокопирование.
- **Большие изображения** возвращаются путями (`local_paths`), а не инлайном — читать через `read_file`.

## Разрешение

- **Целевой размер по умолчанию — 1920×1080** (16:9). Вертикаль для сторис и рилс — 1080×1920, квадрат — 1080×1080. Другой размер задаётся только явно пользователем.
- Генераторы отдают нативный кадр (`aspect_ratio: "16:9"` → 1344×768), поэтому финал всегда проходит цепочку: **генерация → `replicate_upscale_image` (`nightmareai/real-esrgan`, `scale: 4`, $0.003) → Lanczos-даунскейл под целевой размер**.
- Апскейл принимает только URL: локальный файл сначала прогоняется через `replicate_upload_file`, результат скачивается в `local/replicate-output`.
- Точный 16:9 получается кропом по высоте (5376×3072 → 5376×3024) и ресайзом в 1920×1080 — без растяжения кадра.
- `size` и `aspect_ratio` вместе не передавать: при заданном `aspect_ratio` поле `size` игнорируется (проверено на `recraft-v4.1`). У моделей с `size` размер задаётся им, `aspect_ratio` не передаётся.

```py
from PIL import Image, ImageFilter

im = Image.open(src).convert("RGB")
w, h = im.size
th = round(w * 9 / 16)
if h > th:
    top = (h - th) // 2
    im = im.crop((0, top, w, top + th))
im.resize((1920, 1080), Image.LANCZOS).filter(
    ImageFilter.UnsharpMask(radius=1.0, percent=50, threshold=3)
).save(dst, optimize=True)
```

## Инфраструктура

- Токен: `local/replicate-token` (gitignored). Не читать, не логировать, в чат не копировать.
- Запуск сервера: `local/replicate-mcp.cjs` → `npx -y replicate-mcp-server@3.3.0`.
- Каталог моделей без трат: `npx -y replicate-mcp-server@3.3.0 --list-models`.
- Цены в снапшоте сервера отстают для новых моделей — сверять на странице модели.
