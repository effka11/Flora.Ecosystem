# FSA-P — People Search (люди)

**Status:** Active — нормативная спека; реализация v1 в `fsa_core::people`  
**Version:** 0.1  
**Date:** 2026-08-02  
**Depends on:** [`FSA.md`](./FSA.md)

---

## Overview

FSA-P — поиск людей. Домен typeahead-навигационный: подавляющее большинство запросов — начало имени или username, набранное в строку поиска. Профиль включает префиксное расширение с **первого символа**, ранний fuzzy (с 3 символов — имена коротки) и самые сильные exact-boost'ы среди всех поверхностей: точное совпадение username — сильнейший сигнал домена.

---

## Architecture Position

**Владелец данных:** Social Users (`flora-users`). Индексируются публичные карточки профилей. Блокировки (в любом направлении) исключаются владельцем данных до индексации либо на его стороне при выдаче — FSA права не проверяет.

## Профиль (нормативный)

| Поле | Вес | positions | exact_boost |
|------|-----|-----------|-------------|
| `display_name` | 2.2 | ✓ | 0.8 |
| `username` | 2.0 | — | **1.5** |
| `bio` | 0.6 | — | — |
| `interests` | 1.0 | — | — |
| `city` | 0.5 | — | — |

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| recency | Boost, half-life 30 дней, вес 0.1 | лёгкое предпочтение активных профилей (по `last_active_at`) |
| static_rank | 0.6 × profile_rank | заполненность/верификация — сильный глобальный приор |
| proximity | 0.1 | имя+фамилия рядом |
| λ (персонализация) | **0.6** | «мой круг» первым: общие сообщества, темы, знакомые |
| expansion | prefix ≥ **1**, fuzzy ≥ **3** | typeahead с первой буквы; имена короткие |

**Нормативно:** точное совпадение `username` с запросом обязано ранжироваться выше любых частичных совпадений (включая точный `display_name` другого профиля) — отсюда `exact_boost = 1.5` (множитель ×2.5), перекрывающий преимущество более тяжёлого и короткого `display_name`. Инвариант закреплён тестом `exact_username_outranks_partial_matches`.

## Документ

`PersonDoc`: `id`, `display_name`, `username`, `bio?`, `interests[]` (человекочитаемые), `topic_ids[]` (таксономия FIRA), `community_ids[]`, `city?`, `verified`, `last_active_at`, `profile_rank ∈ [0,1]`.

Атрибуты: `verified ∈ {true,false}`.  
Ключи аффинити: `user:{id}` (сила связи с кандидатом из графа), `topic:{topic_id}` (общие интересы), `community:{community_id}` (общие сообщества).

---

## API

`PeopleQuery`: `query`, `limit/offset`, `now`, `personalization (α)`, `verified_only`.

`AffinitySnapshot` для FSA-P собирается композицией из FIRA-P-сигналов: подписки/взаимность → `user:{id}`, UIP-темы → `topic:{id}`, членства → `community:{id}`. Аффинити только переупорядочивает (FSA.md §5.3): при `α = 0` выдача одинакова для всех.
