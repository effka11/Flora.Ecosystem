# Flora — эталон цветоподбора

Документ фиксирует **условия просмотра**, на которых подбиралась UI-палитра Flora (web как первичный эталон), и **признанные брендовые цвета** — `bg`, `whiteTemplate`, `greenLight`, `greenDark` в sRGB hex. Бренд в коде — абстрактные hex, а не «как нарисовал конкретный монитор»; монитор ниже — рабочий инструмент подбора, не сертифицированный color reference.

Зафиксировано: **2026-07-04**. Палитра пересмотрена **2026-11-01** — **Neutral Black + Cold Silver** (два цвета). Действующие значения: `bg #0A0A0A`, `accent / whiteTemplate #DDE2E8`, `textSecondary #B3B7BC`, `signal #FF9688`.

## Первичный эталон (web)

### Монитор

| Параметр | Значение |
|----------|----------|
| Модель | **Philips 272E1GJ** (PHL 272E1GJ) |
| Тип панели | VA LCD, 27", Full HD |
| Разрешение / частота | **1920 × 1080**, **60 Hz** |
| Подключение | NVIDIA GeForce RTX 4060 Ti |
| Variable refresh rate | Не поддерживается |
| Глубина цвета | **8-bit** |
| Формат сигнала | **RGB** |
| Диапазон | **SDR** (стандартный динамический диапазон) |

Источник параметров: Windows → Параметры → Система → Дисплей → Дополнительные параметры дисплея → **Сведения о дисплее** (скрин от 2026-07-04).

### Окружение при подборе цветов

| Параметр | Рекомендация |
|----------|--------------|
| Клиент | **apps/Web** в браузере (Chrome / Edge), без расширений, меняющих цвета |
| Тема ОС | Тёмная |
| HDR Windows | **Выключен** для этого монитора (SDR) |
| Цветовой профиль | sRGB / SDR — не переключать между сессиями подбора |
| Яркость монитора | Одно стабильное значение на время правок (зафиксировать вручную, если меняли) |

### Проверка перед подбором

Монитор приводится к этим условиям и проверяется страницей `tools/monitor-calibration/index.html`
(генерация: `node tools/monitor-calibration/build.mjs`). Тесты: чёрный и белый клиппинг, гамма 2.2 по шахматке,
нейтраль серого клина, тёмная лестница токенов, градиенты, 1 px сетка и текст 15 px. Критерии, порядок
настройки и журнал значений OSD — [`tools/monitor-calibration/README.md`](../../tools/monitor-calibration/README.md).

Страница показывает канонические sRGB-заливки из `globals.css` и `FLORA_THEME_TOKENS` и сверяет бренд-цвета
этого документа. Заливки не измеряются: страница проверяет видимость ступеней и отсутствие искажений, абсолютная
точность остаётся за аппаратным калориметром.

> **Ограничение:** Philips 272E1GJ — потребительский SDR-монитор без заводской color-critical калибровки. Достаточен для day-to-day UI и выбора оттенков; для print/Pantone или юридически точного брендбука нужен отдельный процесс (калибратор, профили).

## Признанные брендовые цвета (sRGB)

Официальная палитра Flora — **два** цвета: **Neutral Black** и **Cold Silver**. Остальные слоты интерфейса — уровни серебра на чёрном; третьего брендового цвета нет. Единственный хроматический акцент UI — служебный `signal` (ошибки, деструктив, бейджи); сердце лайка остаётся на уровне `signal-solid`.

Чёрный выбран нейтральным, с равными RGB-каналами — без синего сдвига. Серебро имеет едва заметный холодный подтон: оно читается как металл, оставаясь нейтральным на разных дисплеях. Контраст серебра на чёрном — **15,20:1** по WCAG; это верхняя точка шкалы, а не требование применять полное серебро ко всему тексту.

| Бренд-токен | CSS (web) | Hex | Роль в идентичности |
|-------------|-----------|-----|---------------------|
| **bg** (Neutral Black) | `--flora-bg` | `#0a0a0a` | Основной фон, нейтральный чёрный |
| **whiteTemplate** (Cold Silver) | `--flora-white-template` | `#dde2e8` | Основной текст и светлые UI-элементы |
| **textSecondary** (Silver 80%) | `--flora-text-secondary` | `#b3b7bc` | Вторичный текст и подписи |
| **accent** (Cold Silver) | `--flora-accent` | `#dde2e8` | Главный акцент (ссылки, активные состояния, заливки, индикаторы) |
| **accentDark** (Silver 18%) | `--flora-accent-dark` | `#303132` | Аватары, границы полей, свой пузырь |
| **signal** | `--flora-signal` | `#ff9688` | Ошибки, деструктивные действия, бейджи |

Исторические имена `--flora-green-light` / `--flora-green-dark` сохранены как алиасы на `--flora-accent` / `--flora-accent-dark`: модули ссылаются на них. Ключи в коде: `FLORA_THEME_TOKENS.bg`, `.whiteTemplate`, `.greenLight`, `.greenDark`.

### Уровни серебра

Вся брендовая шкала строится смешением Cold Silver `#dde2e8` с Neutral Black `#0a0a0a` в sRGB. Контраст — нелинейный показатель WCAG и не совпадает с процентом серебра в смеси.

| Уровень | Hex | Контраст к bg | Роль |
|---------|-----|---------------|------|
| Silver 100% | `#dde2e8` | 15,20:1 | `accent` и основной текст (`whiteTemplate`) |
| Silver 96% | `#d5d9df` | — | текст и иконки на пузыре |
| Silver 80% | `#b3b7bc` | 9,82:1 | вторичный текст (`textSecondary`, `grayHover`) |
| Gray (закреплён) | `#979a9e` | 7,01:1 | приглушённый текст (`gray`) |
| Silver 40% | `#5e6063` | — | обводка пузыря и меню |
| Silver 18% | `#303132` | — | графит: аватары, границы, свой пузырь |
| Silver 8% | `#1b1b1c` | — | подложки списков |
| Silver 6% | `#171717` | — | слабая акцентная заливка |
| Silver 0% | `#0a0a0a` | 1:1 | фон (`bg`) |

Только Android OLED-preview дополнительно показывает `#000000` (пиксели выключены) и `#141414` (приподнятый чёрный) для сравнения с брендовой базой `#0a0a0a`; эти варианты не входят в брендовые токены.

## Служебные цвета UI (не брендовые)

Используются в продукте, но **не входят** в официальную пару бренда:

| Токен | Hex | Назначение |
|-------|-----|------------|
| `signal` / `--flora-signal` | `#ff9688` | Ошибки, деструктивные действия, бейджи; контраст 9,40:1 |
| `like` / `--flora-like` (`signal-solid`) | `#e8382c` | Сердце лайка, точка статуса; не текст |
| `gray` / `--flora-gray` | `#979a9e` | Приглушённый текст, иконки |
| `--flora-on-accent` | `#0a0a0a` | Чёрный текст и иконки на серебряной заливке |
| `--flora-text-on-bubble` | `#d5d9df` | Текст и иконки внутри пузыря |

Производные (substrate, popover, bubble them, grid lines, dividers) — производные от брендовых и служебных; см. `:root` в `globals.css` и `FLORA_THEME_TOKENS`.

На web многие акценты дополнительно смягчаются через **`color-mix(in srgb, …)`** в CSS-модулях; на mobile эквivalent — предвычисленные токены или те же mix-формулы, не «чистый» `greenLight` там, где на web mix.
